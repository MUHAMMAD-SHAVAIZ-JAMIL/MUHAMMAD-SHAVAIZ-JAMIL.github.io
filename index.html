Sleep Detection System

  • Python
  • OpenCV
  • MediaPipe
  • Streamlit
  • Computer Vision

A real-time application that watches the webcam and detects drowsiness from eye closure.

  • MediaPipe Face Mesh extracts facial landmarks around the eyes.
  • The Eye Aspect Ratio (EAR) identifies prolonged eye closure.
  • A Streamlit dashboard shows detection results, and an audio alarm sounds when a sleeping state is detected.

Spam Message Detector

  • Python
  • Scikit-learn
