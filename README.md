# Muhammad Shavaiz Jamil — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — complete portfolio website
- `portrait.jpg` — profile portrait used in the hero section
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing

## Create a new GitHub repository
1. Sign in to GitHub and choose **New repository**.
2. Name it exactly `MUHAMMAD-SHAVAIZ-JAMIL.github.io` (GitHub Pages user-site repositories use the account username).
3. Set visibility to **Public**.
4. Upload all files in this folder to the repository root (not the ZIP file itself).
5. Commit the files.
6. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save if Pages is not already enabled.
7. Your site should publish at `https://muhammad-shavaiz-jamil.github.io`.

## Certificates
The certificate section currently contains 13 official Coursera verification links. The **View / Download** action opens the relevant verification page; use Coursera's PDF download control there when it is available. The actual certificate PDF files were not included in the materials available for this rebuild. To provide direct file downloads from the portfolio itself, add the original certificate PDFs to a `certificates/` folder and change each certificate link to its matching PDF path.
